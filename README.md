# WOW ADDONS FOR NEFARIOUS PURPOSE

A collection of World of Warcraft addons by **Kevon'dre**.

## O BLOCK — World PvP Music

O BLOCK plays random user-supplied local MP3 tracks during open-world PvP, with randomized hype alerts, configurable fade-out, battleground exclusion, and saved settings.

### Install

Download the O BLOCK v1.6 package, extract `OBlock/` into your WoW Forever `Interface/AddOns/` folder, and add your own legally obtained MP3s under `OBlock/Music/` named `track01.mp3`, `track02.mp3`, etc. Restart WoW, enable the addon, then run `/oblock slots 3` and `/oblock test` for a three-song playlist.

### Commands

`/oblock on`, `off`, `test`, `stop`, `slots 1-8`, `fade 0-15`, `status`, `debug`, `about`.

### Notes

Created for WoW Forever (interface 16001). PvP detection is conservative and may miss some engagements. **No commercial music is included or permitted in this repository.** Source license has not yet been selected.
