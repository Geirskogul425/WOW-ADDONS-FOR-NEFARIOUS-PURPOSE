O BLOCK v2.0.4 — Kevon'dre
Install OBlock in Interface/AddOns; retain your existing Music folder and SavedVariables.
Supply your own MP3s, track01.mp3 through track64.mp3, and set the actual count in Playlist.
/oblock opens the settings window. Minimap: left click settings, right click toggle, drag to move.
General: enable, alerts, minimap visibility, fade, reset icon position.
Playlist: track count, individual/random preview, stop. Previews require open world and no combat.
Statistics: session and persistent account-wide totals; detected encounters, combat tracks started,
encounter duration, longest encounter, deaths. Preview tracks excluded. Duration is measured until
combat ends, not verified PvP-only time. Session resets on reload. Existing settings migrate.
Debug: target checks and incoming UNIT_COMBAT diagnostics (no attacker identity assumed).
PvP trigger retains v1.6 conservative hostile-player target heuristic. Incoming damage alone
never starts playback. No independent volume: uses WoW Music channel. No audio included.
Commands: /oblock on, off, test [number], stop, slots 1-64, fade 0-15, status, debug, about.
